# PEPSE PARTS

## تشغيل الموقع

1. تثبيت Node.js إصدار 22.13 أو أحدث من: https://nodejs.org/
2. افتح Terminal داخل مجلد المشروع.
3. شغّل:

```bash
npm install
npm start
```

4. افتح هذا الرابط في المتصفح:

```text
http://localhost:3000
```

## الطلبات ولوحة الإدارة

- الرسائل من نموذج التواصل تحفظ في قاعدة SQLite خارج مجلد ملفات الموقع ثم يفتح واتساب.
- لا تظهر بيانات العميل إلا في خطوة إتمام الطلب. يضيف العميل الأصناف إلى العربة، ثم يفتحها ويختار الشحن أو الاستلام من المحل، ويدخل بيانات الاستلام وطريقة الدفع.
- طلبات الكتالوج لا تحفظ بمجرد فتح واتساب: العميل يرسل الرسالة أولًا ثم يرجع للموقع ويضغط «تم إرسال الطلب - سجّله». إذا ترك رسالة واتساب دون إرسال ولم يؤكد في الموقع، فلن يظهر الطلب في قاعدة البيانات.
- لا يستطيع الموقع التأكد آليًا من أن رسالة واتساب أُرسلت فعلًا أو استلامها؛ زر التأكيد إجراء يدوي من العميل. التحقق الآلي يتطلب WhatsApp Business Platform وإعداد استقبال الرسائل (webhook).
- طرق الدفع الحالية هي الدفع عند الاستلام أو تحويل إنستا باي أو محفظة إلكترونية، وكلا التحويلين يدوي. بيانات إنستا باي المعروضة للعميل هي المستفيد أمجد محمود محمد، بنك CIB، رقم الحساب `100070563945`. رقم المحفظة متغير وترسله المبيعات عبر واتساب. لا يوجد تكامل بوابة دفع إلكتروني بعد؛ طلبات التحويل تظل «بانتظار التحصيل» حتى تراجع الإدارة التحويل وتحدّث حالته من لوحة الإدارة.
- عند اختيار الشحن تكون شركة الشحن والمحافظة والعنوان مطلوبة، مع علامة مميزة اختيارية. عند اختيار الاستلام من المحل لا تُطلب بيانات الشحن ويظهر عنوان الفرع. الإجمالي المعروض لا يشمل تكلفة الشحن.
- بطاقات الكتالوج تعرض السعر بوضوح وتسمح بإضافة الصنف مباشرة إلى العربة دون فتح صفحة التفاصيل؛ إضافة الأصناف لا تفتح العربة تلقائيًا.
- الصور الحقيقية للشاشات تُقرأ من مجلد `lcd-images` ويربطها السيرفر بأسماء أصناف الباندات في Excel بعد توحيد المقاس والخلفية؛ الأصناف بلا صورة مناسبة تستمر بعرض الصورة التوضيحية.
- بحث الكتالوج يتجاهل اختلاف حالة الأحرف والفواصل، ويدعم كتابة آيفون/iPhone وعبارات الشاشة والبطارية. إذا لم يجد تطابقًا مباشرًا يعرض حتى خمسة اقتراحات قريبة، مع احترام التصنيف المختار؛ اختيار اقتراح يفتح الصنف المطابق.
- فلتر GX INCELL يشمل أصناف GX Incell وأصناف Incell التي تبدأ بـIPH أو تنتهي بـOrange/أورنج؛ الفلتر العام Incell يستثنيها.
- فلتر NOKIA / لحام يجمع أصناف النوكيا غير المصنفة وشاشات PIN / رجل؛ لا يوجد فلتر لحام مستقل.
- فلتر VIP يشمل أصناف سيلفر، ولا يظهر JOKER كفلتر مستقل.
- فلتر «ايفونات خلع» يجمع أصناف «أصلي / باغة» و«خلع»، باستثناء NOTE 20 ULTRA الذي يظهر في «توكيل».
- أصناف JT 100% تظهر ضمن فلتر JT الأصلي ولا تظهر ضمن فلتر 100%.
- الأسعار الظاهرة في الكتالوج والسلة ورسالة واتساب تزيد 10 جنيهات عن سعر Excel، باستثناء البطاريات وأصناف JT وOR NEW. التوافر النهائي يؤكده فريق المبيعات؛ تسجيل الطلب لا يخصم المخزون.
- مصدر الكتالوج هو `لسته كامله.xls.xlsx` بجانب `server.js`. يقرأ السيرفر أصناف قسمي LCD والبطاريات فقط، ويستخدم `سعر1` للسعر، ومجموع كميتي «الفرع الرئيسي» و«المحل» للتحقق الداخلي من التوافر. أرقام المخزون لا تُرسل للمتصفح، والأصناف بلا سعر أو بلا كمية متاحة لا تظهر في الكتالوج.
- لا يوجد حد خاص لكمية أصناف JT أو OR NEW؛ تظل الكمية خاضعة للمخزون المتاح والتحقق العام للطلب. لا تنشر ملف Excel أو قاعدة البيانات داخل مجلد عام.
- لتحديد ملف Excel من مسار آخر، اضبط `CATALOG_PATH`. أعد تشغيل السيرفر بعد تحديث الملف.
- فعّل لوحة الإدارة بتعيين كلمة مرور قوية قبل تشغيل السيرفر. مثال PowerShell:

```powershell
$env:ADMIN_PASSWORD = "ضع-كلمة-مرور-قوية-هنا"
npm start
```

- افتح `http://localhost:3000/admin`، واسم المستخدم هو `admin`.
- قاعدة البيانات الافتراضية تحفظ في مجلد `pepse-parts-data` بجانب مجلد المشروع. يمكن تغيير مكانها عبر متغير البيئة `DB_PATH`.
- الصفحة الرئيسية للموقع هي `pag2.html`.
- لتحديث الكميات: احفظ نسخة احتياطية من ملف `لسته كامله.xls.xlsx`، افتحه في Excel، عدّل أعمدة الكمية في صفوف LCD والبطاريات، واحفظ الملف من غير تغيير أسماء الأعمدة أو إضافة علامة تعجب للنسب. عند التحديث الفعلي، أغلق Excel أولًا وأعد تشغيل السيرفر بـ `npm start`; عند التشغيل سيقرأ الكميات والأسعار الجديدة تلقائيًا. لا تنشر ملف Excel أو تضفه ضمن مجلد عام على الاستضافة.
- طريقة رفع التحديث من لوحة الإدارة: ادخل `/admin` بكلمة مرور الأدمن، اختر قسم «تحديث ملف الكتالوج والكميات»، ارفع ملف `.xlsx` جديدًا، واضغط «رفع وتطبيق التحديث». ينشئ النظام نسخة احتياطية خارج مجلد الملفات العامة ويختبر الملف قبل استبداله؛ عند نجاح الرفع يتحدث الكتالوج فورًا من غير إعادة تشغيل.
- لتفعيل الحماية عند النشر: استخدم HTTPS، لا تشارك كلمة مرور الأدمن أو بيانات الخدمة، واحفظ نسخة احتياطية من قاعدة الطلبات خارج المشروع. استخدم نسخة إنتاج منفصلة واقفل وصول المنافذ والمسار العام عن مجلد المشروع وملف Excel.
- لا يمكن إخفاء HTML/CSS/JavaScript تمامًا عن متصفح المستخدم؛ المتصفح يحتاجها لعرض الموقع. الحماية الحقيقية هي خادم معتمد، عدم نشر الأسرار والقاعدة والـExcel، تفعيل HTTPS، وقصر لوحة الأدمن بكلمة مرور قوية. ضغط/تصغير الكود يعطل القراءة لكنه لا يمنع النسخ؛ ولا يثبت الملكية وحده.
- حقوق الموقع والتصميم والمحتوى تعود لـPEPSE PARTS باسم صاحب العمل، ما لم يوجد ترخيص مكتوب بغير ذلك. لتثبيت ذلك مهنيًا: أضف سياسات حقوق الملكية في الفوتر/شروط الاستخدام، وسجّل العلامة أو البرمجيات عند الحاجة، وخذ نسخة تأريخية موثقة من النسخة المنشورة، ولا تستخدم وسائلًا تدمر الجهاز أو تمنع النسخ بشكل زائد.
- عند النشر على الإنترنت، استخدم استضافة توفر قرصًا دائمًا، واحمِ الموقع باتصال HTTPS، واضبط `ADMIN_PASSWORD` و`DB_PATH` كإعدادات سرية/بيئية في الاستضافة. لا تضع ملف قاعدة البيانات ضمن مجلد الملفات العامة، وخذ نسخة احتياطية منتظمة.
- صفحة الإدارة تعرض آخر 300 طلب أو رسالة، وتتيح تغيير الحالة إلى جديد أو مؤكد أو تم الشحن أو ملغي.
